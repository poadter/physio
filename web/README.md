# กายภาพ AI

ระบบช่วยฝึกกายภาพบำบัดที่บ้านสำหรับผู้สูงอายุ ใช้กล้องมือถือ + AI จับท่าทาง

- **ผู้ฝึก (ผู้สูงอายุ):** ฝึก 5 ท่า AI นับครั้งให้ บอกด้วยเสียงภาษาไทยว่าทำถูกหรือต้องแก้ตรงไหน ถามอาการก่อน/หลังฝึก ตรวจจับการล้ม ปุ่มขอความช่วยเหลือ
- **โหมดเรียนท่า:** ตัวการ์ตูนสาธิตท่าพร้อมเสียงอธิบายทีละขั้น แล้วให้ลองทำตาม AI สอน 3 ขั้น (ตั้งกล้อง → ท่าเริ่มต้น → ลองทำ) ผ่านเมื่อทำถูก 3 ครั้ง
- **นักกายภาพ:** เพิ่มผู้ฝึก กำหนดท่า/จำนวนครั้ง/องศารายบุคคล ดูกราฟพัฒนาการ จุดที่ทำผิดบ่อย รับแจ้งเตือน และโหมด "ทดลองท่า" สำหรับสอนและวัดองศา
- **ผู้ป่วยโรคหลอดเลือดสมอง (Stroke):** โปรแกรมฝึกตั้งต้นตามโรค ระบุข้างที่อ่อนแรง วัดแยกซ้าย-ขวาแล้วแสดงว่าข้างอ่อนแรงขยับได้กี่ % ของข้างปกติ ถามสัญญาณเตือนสโตรค (หน้าเบี้ยว แขนขาอ่อนแรง พูดไม่ชัด) ก่อนฝึก ถ้ามีอาการให้โทร 1669 และแจ้งญาติทันที
- **โรคอื่นที่ตั้งโปรแกรมไว้:** ข้อเข่าเสื่อม, หลังเปลี่ยนข้อเข่า, ไหล่ติด, ผู้สูงอายุเสี่ยงล้ม
- **ญาติ:** สแกน QR ด้วย LINE เพื่อรับแจ้งเตือนเมื่อ ล้ม · ขอความช่วยเหลือ · เจ็บมาก · ไม่ได้ฝึก · ผลการฝึกลดลง และพิมพ์ "สถานะ" ดูผลการฝึกได้

| ท่า | วัดอะไร | ตั้งกล้อง |
|---|---|---|
| 🪑 ลุก-นั่งจากเก้าอี้ | มุมเข่า + ลำตัวตรง | ด้านข้าง |
| 🙌 ยกแขนเหนือศีรษะ | มุมไหล่ + ศอกเหยียด + สองข้างเท่ากัน | ด้านหน้า |
| 🦵 นั่งเหยียดเข่า | มุมเข่า + ค้าง 2 วินาที | ด้านข้าง |
| 🚶 ยกเข่าย่ำเท้า | องศายกสะโพก + ลำตัวตรง | ด้านข้าง |
| 🦶 เขย่งปลายเท้า | ความสูงส้นเท้า + ค้าง 1 วินาที | ด้านข้าง (ระดับเข่า) |
