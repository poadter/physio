# คู่มือติดตั้ง กายภาพ AI

ใช้บริการฟรีทั้งหมด ไม่ต้องผูกบัตรเครดิต ใช้เวลาติดตั้งประมาณ 1–2 ชั่วโมง

| ส่วน | ใช้อะไร | ต้องมี |
|---|---|---|
| เซิร์ฟเวอร์ + ฐานข้อมูล | Google Apps Script + Google Sheets | บัญชี Google (Gmail) |
| หน้าเว็บแอป | GitHub Pages (หรือ Netlify) | บัญชี GitHub |
| แจ้งเตือน | LINE Official Account + LINE Developers | บัญชี LINE |

> **อยากลองก่อนติดตั้ง?** ข้ามไปทำขั้นที่ 3 ได้เลยโดยไม่ต้องแก้ `config.js` แอปจะทำงานใน **โหมดทดลอง** ฝึกท่า นับครั้ง และฟังเสียงได้ทันที (แต่ยังไม่บันทึกขึ้นระบบและไม่ส่ง LINE)

## ขั้นที่ 1 — เตรียมไฟล์

แตกไฟล์ `physio-ai.zip` จะได้โฟลเดอร์

```
physio-ai/
├── web/            ← หน้าเว็บแอป (อัปโหลดขึ้น GitHub Pages)
├── backend/
│   └── Code.gs     ← โค้ดเซิร์ฟเวอร์ (วางใน Apps Script)
├── tests/          ← ชุดทดสอบ (ไม่ต้องอัปโหลด)
└── INSTALL.md      ← ไฟล์นี้
```

## ขั้นที่ 2 — ติดตั้งเซิร์ฟเวอร์ (Google Apps Script)

1. เข้า <https://sheets.new> สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `กายภาพ AI - ข้อมูล`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ว **วางโค้ดจาก `backend/Code.gs`** → กด 💾 บันทึก
4. ช่องเลือกฟังก์ชันด้านบน เลือก **`setup`** → กด **▶ เรียกใช้**
   - Google จะขอสิทธิ์ → เลือกบัญชี → **ขั้นสูง** → **ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต**
     (ขึ้นคำเตือนเพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ใช่ไวรัส)
   - กลับไปดู Google Sheet จะมีแผ่นงานใหม่ 5 แผ่น: Patients, Sessions, Alerts, Family, LinkCodes
5. ไอคอน ⚙️ **การตั้งค่าโปรเจ็กต์** (แถบซ้าย) → เลื่อนลงไปที่ **พร็อพเพอร์ตี้ของสคริปต์** → **แก้ไขพร็อพเพอร์ตี้ของสคริปต์**
   - `ADMIN_PIN` = รหัสเข้าหน้านักกายภาพ **อย่างน้อย 6 หลัก** (เช่น `583914`)
   - ค่าของ LINE ใส่ภายหลังในขั้นที่ 4
6. ปุ่ม **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ⚙️ เลือกประเภท → **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** ← สำคัญ ถ้าเลือกผิด แอปจะเชื่อมต่อไม่ได้
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
7. ทดสอบ: เปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"data":{"app":"PhysioAI",...}}`

> **แก้โค้ดเซิร์ฟเวอร์ภายหลัง:** วางโค้ดใหม่ → บันทึก → **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** (URL เดิมยังใช้ได้ ไม่ต้องแก้แอป)

## ขั้นที่ 3 — ติดตั้งหน้าเว็บแอป (GitHub Pages)

1. เปิดไฟล์ `web/config.js` ด้วย Notepad แก้บรรทัด

   ```js
   API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```

   และแก้ `APP_NAME`, `ORG_NAME` ตามต้องการ แล้วบันทึก

2. เข้า <https://github.com> → สมัคร/เข้าสู่ระบบ → ปุ่ม **New** (สร้าง repository)
   - Repository name เช่น `physio` → เลือก **Public** → **Create repository**
3. คลิกลิงก์ **uploading an existing file** → ลาก **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างใน `web/`** (ไม่ใช่ตัวโฟลเดอร์ web) มาวาง → **Commit changes**
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อผู้ใช้.github.io/physio/`

ทดสอบ: เปิด `https://ชื่อผู้ใช้.github.io/physio/admin.html` → ใส่ PIN → ต้องเข้าได้

> **ทางเลือก Netlify:** สมัคร <https://app.netlify.com> → **Add new site → Deploy manually** → ลากโฟลเดอร์ `web` ไปวาง ได้ลิงก์ https ทันที
>
> ⚠️ ต้องเป็นลิงก์ **https** เท่านั้น มือถือจึงจะยอมเปิดกล้อง

## ขั้นที่ 4 — ตั้งค่า LINE แจ้งเตือนญาติ

### 4.1 สร้างบัญชี LINE ทางการ + เปิด Messaging API

1. เข้า <https://manager.line.biz> → สร้างบัญชี LINE Official Account (ชื่อเช่น `แจ้งเตือนกายภาพ`)
2. ในบัญชีนั้น: **ตั้งค่า (Settings) → Messaging API → เปิดใช้ Messaging API (Enable)** → สร้าง/เลือก **Provider** (จำไว้ จะใช้ซ้ำในข้อ 4.3)
3. ยังอยู่ใน LINE Official Account Manager: **ตั้งค่าการตอบกลับ (Response settings)**
   - ปิด **ข้อความตอบกลับอัตโนมัติ (Auto-reply)** และ **ข้อความทักทาย (Greeting)**
   - เปิด **Webhook**
4. จดค่า **Basic ID** ของบัญชี (ขึ้นต้นด้วย @ เช่น `@123abcde`)

### 4.2 ตั้งค่าใน LINE Developers

1. เข้า <https://developers.line.biz/console> ด้วยบัญชีเดียวกัน → เลือก Provider → เลือกช่อง (channel) ของบัญชี LINE ทางการ
2. แท็บ **Messaging API**
   - **Channel access token (long-lived)** → กด **Issue** → คัดลอก
   - **Webhook URL** → ใส่ URL `/exec` จากขั้นที่ 2 → **Update** → เปิด **Use webhook**
   - ปุ่ม Verify อาจขึ้น error เพราะ Google ตอบกลับแบบ redirect **ไม่เป็นไร** ระบบยังใช้งานได้ (ทดสอบโดยพิมพ์ "สถานะ" หาบัญชี จะมีข้อความตอบกลับ)

### 4.3 สร้าง LIFF (หน้าเชื่อมต่อญาติด้วย QR)

1. ใน Provider **เดียวกัน** (สำคัญ ถ้าคนละ Provider ระบบจะจับคู่ญาติไม่ได้) → **Create a new channel → LINE Login**
   - App types: **Web app** → กรอกชื่อ/คำอธิบาย → Create
2. แท็บ **Basic settings**
   - คัดลอก **Channel ID**
   - **Linked LINE Official Account** → เลือกบัญชีจากข้อ 4.1
3. แท็บ **LIFF → Add**
   - Size: **Full**
   - Endpoint URL: `https://ชื่อผู้ใช้.github.io/physio/liff.html`
   - Scopes: ✅ **openid** ✅ **profile**
   - Add friend option: **On (Aggressive)**
   - กด **Add** → คัดลอก **LIFF ID** (เช่น `2001234567-AbCdEfGh`)
4. ด้านบนของหน้าช่อง กดเปลี่ยนสถานะจาก **Developing → Published** (ถ้าไม่ทำ คนอื่นที่ไม่ใช่ผู้พัฒนาจะเข้าไม่ได้)

### 4.4 ใส่ค่าใน Apps Script

กลับไป Apps Script → ⚙️ การตั้งค่าโปรเจ็กต์ → พร็อพเพอร์ตี้ของสคริปต์ → เพิ่มค่า

| พร็อพเพอร์ตี้ | ค่า |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | จากข้อ 4.2 |
| `LINE_OA_ID` | Basic ID เช่น `@123abcde` |
| `LINE_LOGIN_CHANNEL_ID` | Channel ID จากข้อ 4.3 |
| `LIFF_ID` | LIFF ID จากข้อ 4.3 |
| `MISSED_DAYS` | แจ้งเตือนเมื่อไม่ได้ฝึกกี่วัน (ค่าเริ่มต้น 2) |

ไม่ต้อง Deploy ใหม่ ค่าจะมีผลทันที → เปิดหน้านักกายภาพ แท็บ **สถานะระบบ** ต้องขึ้น "พร้อม" ทุกบรรทัด

> ถ้ายังไม่ทำข้อ 4.3 ระบบยังใช้ได้ ญาติเชื่อมต่อโดย **แอดเพื่อนบัญชี แล้วพิมพ์รหัส 6 หลัก** ที่แสดงในแอปแทนการสแกน

## ขั้นที่ 5 — ทดสอบทั้งระบบ (10 นาที)

1. **นักกายภาพ:** เปิด `.../admin.html` → ใส่ PIN → **เพิ่มผู้ฝึก** → เลือกท่า → บันทึก → ขึ้น QR
2. **ผู้ฝึก:** ใช้กล้องมือถือสแกน QR → เปิดแอป → กด **📲 ติดตั้งแอปลงหน้าจอ**
3. **ญาติ:** ในแอปผู้ฝึก กด **เชื่อมต่อญาติ** → ญาติสแกน QR ด้วย LINE → ยืนยัน → **แอดเพื่อน**
4. ในแอปผู้ฝึก กด **อนุญาต** → ญาติได้รับ LINE "เชื่อมต่อสำเร็จ"
5. **ฝึก 1 ท่า** → ดูผลในหน้านักกายภาพ
6. กด **🆘 ขอความช่วยเหลือ** → ญาติต้องได้รับ LINE ภายในไม่กี่วินาที
7. หน้านักกายภาพ แท็บสถานะระบบ → **ตรวจรายวันตอนนี้** (ระบบจะตรวจเองทุกวัน 18:00 น.)

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| แอปขึ้น "เซิร์ฟเวอร์ตอบกลับผิดรูปแบบ" | Deploy เลือก "ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน" ไม่ถูก หรือ URL ใน `config.js` ไม่ลงท้าย `/exec` |
| เปิดกล้องไม่ได้ | ต้องเปิดผ่าน https และกดอนุญาตกล้อง (iPhone: ตั้งค่า → Safari → กล้อง → อนุญาต) |
| โหลด AI นาน | ครั้งแรกต้องดาวน์โหลดประมาณ 10 MB ครั้งต่อไปเร็วขึ้นเพราะเก็บไว้ในเครื่อง |
| ไม่มีเสียงพูด | ตั้งค่ามือถือ → การช่วยการเข้าถึง → อ่านออกเสียง → ติดตั้งเสียงภาษาไทย และเปิดเสียงมือถือ |
| นับไม่ขึ้น / นับผิด | ตั้งกล้องให้เห็นทั้งตัว ถ่ายด้านข้างสำหรับท่าที่ระบุ แสงพอ ใช้ "ทดลองท่า" ดูองศาจริง แล้วปรับค่าในแผนการฝึก |
| ญาติไม่ได้รับ LINE | ญาติต้อง **แอดเพื่อน** บัญชีแล้ว + สถานะ "อนุญาต" แล้ว + ตรวจ `LINE_CHANNEL_ACCESS_TOKEN` + ใช้ปุ่ม "ส่งข้อความทดสอบ" |
| สแกน QR แล้วขึ้น "ยืนยันตัวตน LINE ไม่สำเร็จ" | LINE Login คนละ Provider กับบัญชีทางการ หรือ `LINE_LOGIN_CHANNEL_ID` ผิด หรือยังไม่ได้ Published |
| iPhone ติดตั้งแอปแล้วถามรหัสอีก | ปกติของ iPhone ให้กด "สแกน QR Code" ในแอป แล้วสแกน QR จากนักกายภาพอีกครั้ง |
| แก้หน้าเว็บแล้วมือถือยังเป็นของเก่า | เปลี่ยน `VERSION` ใน `web/sw.js` เช่น `physio-v2` แล้วอัปโหลดใหม่ |

## อัปเดตเซิร์ฟเวอร์ภายหลัง

เมื่อได้ `Code.gs` ชุดใหม่: วางโค้ดใหม่ทับใน Apps Script → บันทึก → **เรียกใช้ `setup` อีกครั้ง** (เพิ่มคอลัมน์ใหม่ใน Sheet โดยข้อมูลเดิมไม่หาย) → **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชันใหม่ → ทำให้ใช้งานได้**

## อัปเดตแอปภายหลัง (เช่น เพิ่มโหมดเรียนท่า)

1. เปิด repository บน GitHub → เข้าโฟลเดอร์ที่เก็บแอป (ถ้าอัปโหลดทั้งชุด คือโฟลเดอร์ `web`)
2. **Add file → Upload files** → ลากไฟล์และโฟลเดอร์ทั้งหมดข้างใน `web/` ชุดใหม่มาวางทับ → **Commit changes**
3. ⚠️ ถ้าแก้ `config.js` ไว้แล้ว (ใส่ API_URL) **อย่าอัปโหลด config.js ทับ** หรือแก้ API_URL ในไฟล์ใหม่ก่อน
4. รอ 1–2 นาที แล้วปิด-เปิดแอปในมือถือใหม่ 2 ครั้ง เพื่อให้โหลดเวอร์ชันใหม่

## ข้อจำกัดและความปลอดภัย

- ใช้เป็น **เครื่องมือช่วยฝึกที่บ้าน** ภายใต้การดูแลของนักกายภาพ ไม่ใช่อุปกรณ์การแพทย์ ไม่ใช้วินิจฉัยหรือแทนการประเมินโดยผู้เชี่ยวชาญ
- การตรวจการล้มทำงาน **เฉพาะตอนเปิดหน้าฝึก** และอาจพลาดได้ (เช่น ล้มนอกมุมกล้อง)
- ภาพจากกล้อง **ประมวลผลในมือถือเท่านั้น** ไม่ถูกส่งหรือบันทึกที่ใด เซิร์ฟเวอร์เก็บเฉพาะตัวเลขผลการฝึก
- ข้อมูลสุขภาพอยู่ใน Google Sheet ของคุณ **อย่าแชร์ไฟล์ Sheet** ให้คนที่ไม่เกี่ยวข้อง ขอความยินยอมผู้ป่วยก่อนเก็บข้อมูลตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA)
- QR ลงทะเบียนเครื่องใช้แทนรหัสผ่านของผู้ฝึก ถ้าหลุดให้กด "เปลี่ยนรหัสลับ"
- บัญชี LINE ทางการแบบฟรีมีโควตาข้อความ push จำกัดต่อเดือน ข้อความตอบกลับ (เช่น "สถานะ") ไม่นับโควตา ตรวจโควตาได้ใน LINE Official Account Manager
- เหมาะกับการใช้งานระดับหน่วยงาน/โครงการ (หลักสิบถึงหลักร้อยคน) ถ้าจะขยายเป็นระดับโรงพยาบาล ควรย้ายฐานข้อมูลไประบบที่มีมาตรฐานความปลอดภัยสูงกว่า

```bash

node tests/e2e/server.mjs &      # เปิดระบบจำลองที่ http://localhost:8000
python3 tests/e2e/run_e2e.py     # ทดสอบทั้งระบบในเบราว์เซอร์ (ต้องมี Playwright)
```

- ข้อความแจ้งเตือน LINE: แก้ที่ `ALERT_TEXT` ใน `backend/Code.gs`
